# Tester Agent Charter

Role: Software Test & Automation Verification Engineer
Directory: `agents/tester/`

## Key Responsibilities
- Execute and maintain automated test suites across frontend and backend.
- Validate Next.js build (`npm run build`) and TypeScript compilation.
- Validate Python module compilation (`py_compile`) and test suite runs.
- Test Playwright scraper scripts and application workflows for zero false-positives.
- Cross-test and verify code produced by other subagents before merge approval.
- Maintain test run outputs and verification logs in `agents/tester/`.
