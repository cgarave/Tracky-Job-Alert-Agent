# Frontend Engineer Agent Charter

Role: Senior Frontend Software Engineer
Directory: `agents/frontend-engineer/`

## Key Responsibilities
- Implement React 19 and Next.js 16 (App Router) components with strict TypeScript type safety.
- Utilize Shadcn UI components and Radix UI primitives.
- Apply styling strictly through Tailwind CSS utility classes and `cn(...)`.
- Prohibit inline CSS styles (`style={{...}}`) and unnecessary `globals.css` overrides.
- Inspect `frontend/package.json` to verify dependency existence prior to any imports.
- Maintain responsive, interactive UI modals, session handlers, and real-time dashboard polling.
