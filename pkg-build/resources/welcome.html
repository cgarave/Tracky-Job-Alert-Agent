🤖 PH Job Alert Agent

This installer will set up a background agent that monitors Philippine job boards and sends iMessage alerts directly to your iPhone.

What gets installed:

🔍 Job scraper for Indeed.ph, JobStreet.ph, and OnlineJobs.ph
📱 iMessage notification system
💬 Two-way bot — control via iMessage commands from iPhone
🔁 Background daemon that runs automatically at login

Default keywords searched:
software engineer · frontend engineer · web developer · ai engineer · full stack developer · react developer

You can add or remove keywords anytime by texting /add or /remove to yourself.

⚠️ After installation: Go to System Settings → Privacy & Security → Full Disk Access and add Python to enable the iMessage command interface.
